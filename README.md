# Hitman-World-of-Ai-bot-

## Configuration

Create a `.env` file in the project root:

```env
GEMINI_API_KEY=your_api_key_here
AI_PERSONALITY=balanced
ENABLE_TTS=true
```

Supported `AI_PERSONALITY` values:
- `balanced` (default)
- `cautious`
- `aggressive`

`ENABLE_TTS` controls spoken narration of the AI's thought/action (`true` by default).
